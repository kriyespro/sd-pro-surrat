# Fix 502 Bad Gateway on :8787

**502** = Docker nginx is up, but **web** (Gunicorn) is not running or not reachable.

## 1) Diagnose (run on VPS)

```bash
cd /opt/suratpro/sd-pro-surrat
docker compose -f docker-compose.prod.yml ps
docker compose -f docker-compose.prod.yml logs web --tail 80
```

If `web` shows **Exit** or **Restarting**, read the log lines above the crash.

## 2) Most common fix — Postgres SSL (Docker)

Production had `ssl_require=True` but internal Postgres has no SSL.

Add to `.env.prod`:

```env
DATABASE_SSL_REQUIRE=False
```

Pull latest code (includes settings fix), rebuild:

```bash
git pull origin main
docker compose -f docker-compose.prod.yml --env-file .env.prod up -d --build
```

## 3) Quick test without full rebuild

```bash
docker compose -f docker-compose.prod.yml exec web python manage.py check
docker compose -f docker-compose.prod.yml exec web python -c "
import os; os.environ.setdefault('DJANGO_SETTINGS_MODULE','core.settings')
import django; django.setup()
from django.db import connection
connection.ensure_connection()
print('DB OK')
"
```

## 4) If web still down — manual migrate

```bash
docker compose -f docker-compose.prod.yml exec web python manage.py migrate --noinput
docker compose -f docker-compose.prod.yml restart web
```

## 5) Success check

```bash
curl -I http://127.0.0.1:8787/
# Expect: HTTP/1.1 200 or 302 (not 502)
```
