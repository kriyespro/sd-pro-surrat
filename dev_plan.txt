PHASE 1 — AUTH & USER PROFILES  (Day 2-3)
================================================================================

FEATURE MAP (durga.txt lines 1-5):
  Freelancer & client profiles · Skills, portfolio & bio
  Verified badges · Ratings & reviews

MODELS (users/models.py):
  class User(AbstractUser):
      role = CharField(choices=['client','freelancer'])
      phone = CharField()
      avatar = ImageField()
      city = CharField()        # Surat locality
      bio = TextField()
      is_verified = BooleanField()
      referral_code = CharField()
      created_at = DateTimeField()

  class FreelancerProfile(Model):
      user = OneToOneField(User)
      title = CharField()           # "Full-Stack Developer"
      skills = ManyToManyField(Skill)
      hourly_rate = DecimalField()
      min_project = DecimalField()
      availability = CharField()    # online/busy/offline
      response_time = CharField()
      portfolio_url = URLField()
      linkedin = URLField()
      experience_years = IntegerField()

  class Skill(Model):
      name = CharField(unique=True)
      category = ForeignKey(Category)

  class Category(Model):
      name = CharField()
      icon = CharField()            # emoji
      slug = SlugField()

  class PortfolioItem(Model):
      freelancer = ForeignKey(FreelancerProfile)
      title = CharField()
      description = TextField()
      image = ImageField()
      url = URLField()
      tags = ManyToManyField(Skill)

  class Certification(Model):
      freelancer = ForeignKey(FreelancerProfile)
      title = CharField()
      issuer = CharField()
      year = IntegerField()

VIEWS (users/views.py):
  RegisterView      → POST /auth/register/
  LoginView         → POST /auth/login/
  LogoutView        → POST /auth/logout/
  ProfileView       → GET  /profile/<username>/        → profile.jinja
  ProfileEditView   → GET/POST /dashboard/profile/edit/
  OnboardingView    → GET/POST /onboarding/            → role + basic info

URLS: users/urls.py → prefix: auth/ + profile/ + onboarding/

TEMPLATES:
  pages/auth/login.jinja     ← login.html (tab: login/register)
  pages/auth/register.jinja  ← login.html (tab: register, role cards)
  pages/profile.jinja        ← profile.html (about/portfolio/reviews tabs)
  pages/onboarding.jinja     ← new: step wizard

HTMX:
  hx-post="/auth/login/"          → swap #auth-form with errors or redirect
  hx-post="/auth/register/"       → same
  hx-get="/profile/edit/skills/"  → swap #skills-section (live skill add)

FORMS:
  RegisterForm / LoginForm / ProfileEditForm / FreelancerProfileForm

PHASE 5 — CONTRACTS & MILESTONES  (Day 9-10)
================================================================================

FEATURE MAP (durga.txt lines 21-25):
  Digital contract signing · Milestone-based payments
  Deliverable tracking · Revision requests

MODELS (contracts/models.py):
  class Contract(Model):
      job = ForeignKey(Job)
      client = ForeignKey(User, related_name='client_contracts')
      freelancer = ForeignKey(User, related_name='freelancer_contracts')
      proposal = ForeignKey(Proposal)
      total_value = DecimalField()
      status = CharField(choices=['active','completed','disputed','cancelled'])
      signed_by_client = BooleanField()
      signed_by_freelancer = BooleanField()
      signed_at = DateTimeField()
      created_at = DateTimeField()

  class Milestone(Model):
      contract = ForeignKey(Contract)
      title = CharField()
      description = TextField()
      amount = DecimalField()
      due_date = DateField()
      status = CharField(choices=['pending','submitted','approved','released'])
      order = IntegerField()

  class Deliverable(Model):
      milestone = ForeignKey(Milestone)
      file = FileField()
      note = TextField()
      submitted_at = DateTimeField()

  class RevisionRequest(Model):
      milestone = ForeignKey(Milestone)
      requested_by = ForeignKey(User)
      note = TextField()
      created_at = DateTimeField()

VIEWS (contracts/views.py):
  ContractView          → GET  /contracts/<id>/
  SignContractView      → POST /contracts/<id>/sign/
  SubmitDeliverable     → POST /milestones/<id>/submit/
  ApproveMilestone      → POST /milestones/<id>/approve/
  RequestRevisionView   → POST /milestones/<id>/revision/

TEMPLATES:
  pages/contract.jinja
  partials/_milestone_card.jinja
  partials/_deliverable_upload.jinja

HTMX:
  hx-post="/contracts/5/sign/"          → swap #contract-status
  hx-post="/milestones/3/approve/"      → swap #milestone-3 with approved state
  hx-post="/milestones/3/submit/"       → file upload + swap

PHASE 6 — SECURE PAYMENTS & ESCROW  (Day 11-12)
================================================================================

FEATURE MAP (durga.txt lines 26-30):
  Escrow/fund hold · UPI, card, net banking
  Auto-release on approval · Dispute & refund system

MODELS (payments/models.py):
  class Wallet(Model):
      user = OneToOneField(User)
      balance = DecimalField()
      escrow_balance = DecimalField()
      updated_at = DateTimeField()

  class Transaction(Model):
      wallet = ForeignKey(Wallet)
      type = CharField(choices=['topup','escrow','release','refund','payout'])
      amount = DecimalField()
      ref_id = CharField()           # Razorpay order/payment id
      contract = ForeignKey(Contract, null=True)
      milestone = ForeignKey(Milestone, null=True)
      status = CharField(choices=['pending','success','failed'])
      created_at = DateTimeField()

  class Dispute(Model):
      contract = ForeignKey(Contract)
      raised_by = ForeignKey(User)
      reason = TextField()
      status = CharField(choices=['open','in_review','resolved','closed'])
      resolution = TextField()
      created_at = DateTimeField()

SERVICES (payments/services.py):
  def create_razorpay_order(amount, user)
  def verify_payment(order_id, payment_id, signature)
  def fund_escrow(wallet, contract, amount)
  def release_milestone(milestone)           # auto-release on approval
  def process_refund(transaction)
  def calculate_commission(amount, user)     # 15% free / 10% pro

VIEWS (payments/views.py):
  PaymentsPageView     → GET  /payments/       → payments.jinja
  AddFundsView         → POST /payments/add/
  RazorpayCallbackView → POST /payments/callback/
  ReleaseFundsView     → POST /payments/release/<milestone_id>/
  TransactionListView  → GET  /payments/transactions/ → partial
  DisputeView          → POST /payments/dispute/<contract_id>/

TEMPLATES:
  pages/payments.jinja            ← payments.html
  partials/_transaction_row.jinja
  partials/_release_modal.jinja
  partials/_add_funds_form.jinja

HTMX:
  hx-post="/payments/add/"        → Razorpay JS opens, on success callback
  hx-post="/payments/release/3/"  → swap #release-modal with success
  hx-get="/payments/transactions/?type=Escrow" → live filter swap
